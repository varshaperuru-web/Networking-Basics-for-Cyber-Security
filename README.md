# Networking-Basics-for-Cyber-Security
Beginner-friendly notes and practical documentation on Networking Basics for Cyber Security. Covers IP, MAC, DNS, TCP/UDP concepts, Wireshark packet capture, filtering, TCP handshake analysis, DNS queries, encrypted vs plain-text traffic, and real-world security observations.

## Networking Basics for Cyber Security
### Overview

This repository contains beginner-friendly study notes and practical documentation for Networking Basics in Cyber Security. It focuses on understanding how network communication works and how packet analysis helps in identifying security threats. The content is designed for internship tasks, lab records, and academic evaluation.

## Objectives

Understand basic networking concepts used in cybersecurity
Learn how data flows across a network
Analyze network traffic using packet capturing tools
Identify insecure and secure network communication
Build a strong foundation for advanced cybersecurity topics

## Tools Used
### Primary Tool

Wireshark – Network packet analyzer used for capturing and inspecting live traffic

### Alternative Tools

tcpdump – Command-line packet capture tool
Microsoft Network Monitor – Windows-based network analysis tool

## Concepts Covered

Networking fundamentals (IP, MAC, DNS)
TCP vs UDP communication
HTTP vs HTTPS traffic
Packet sniffing and traffic analysis
Three-way TCP handshake
DNS query and response analysis
Plain-text vs encrypted traffic
Common network-based attacks

## Practical Tasks Performed

Studied basic networking concepts (IP, MAC, DNS, TCP/UDP)
Installed Wireshark and captured live network traffic
Filtered packets using protocol filters (HTTP, DNS, TCP)
Observed the TCP three-way handshake
Identified encrypted and plain-text traffic
Captured and analyzed DNS queries
Saved packet capture files for analysis
Documented observations in simple language

## Key Learnings

Every online activity generates network packets
TCP connections follow a fixed handshake process
DNS plays a critical role before loading any website
Encrypted traffic protects sensitive data
Packet analysis is essential for detecting cyber attacks

## Final Outcome

This repository helps in developing a clear understanding of networking concepts from a cybersecurity perspective. It strengthens the foundation required for network monitoring, threat detection, and incident analysis.
